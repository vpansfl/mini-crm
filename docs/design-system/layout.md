# 레이아웃

구현 위치: `frontend/src/layouts/AppLayout.css`, `frontend/src/styles/ui.css`.

## 앱 셸

```
┌──────────────┬───────────────────────────────────────────────┐
│ Sidebar      │  Canvas (#FBFBFA)                              │
│ 240px, 흰색   │  ┌───────── max-width 1200px ─────────┐        │
│ sticky       │  │ PageHeader (제목 + 행동 버튼)        │        │
│              │  │ 콘텐츠 (카드 / 테이블 / 폼)          │        │
│              │  └─────────────────────────────────────┘        │
└──────────────┴───────────────────────────────────────────────┘
```

- 사이드바: 너비 240px, 화면 높이에 고정(sticky), 흰 표면 + 오른쪽 1px 테두리.
- 본문: 캔버스 배경, 안쪽 여백 데스크톱 `--space-xl`(32px) / `--space-2xl`(48px) 좌우, 콘텐츠 **최대 폭 1200px** (왼쪽 정렬이 아닌 본문 영역 안에서 가운데 정렬).
- 넓은 테이블은 `.table-wrap`에서 가로 스크롤.

## 페이지 구조

1. `PageHeader` — 뒤로가기(상세 화면), 제목, 설명, 오른쪽 행동 버튼.
2. 알림(`.notice`) — mutation 결과/오류.
3. 콘텐츠 — 섹션 간 간격 `--space-lg`(24px), 섹션 제목은 `.card-title`.

## 그리드

| 클래스 | 데스크톱 | ≤ 1100px | ≤ 640px |
|---|---|---|---|
| `.grid-4` | 4열 (KPI 카드) | 2열 | 1열 |
| `.grid-2` | 2열 (차트, 정보 카드) | 1열 | 1열 |

간격은 `--space-md`(16px).

## 반응형 기준

MVP는 **데스크톱(> 1024px) 우선**이다. 작은 화면은 깨지지 않을 정도만 지원한다.

| 구간 | 동작 |
|---|---|
| > 1024px | 기본 레이아웃 |
| 641 ~ 1024px | 본문 좌우 여백 `--space-lg` |
| ≤ 768px | 사이드바가 상단 가로 바로 바뀜 (메뉴 가로 스크롤), 페이지 제목 `headline-xl-mobile`(26px) |
| ≤ 640px | 본문 좌우 여백 `--space-md`, 그리드 1열, 페이지 헤더 버튼은 제목 아래로 |
